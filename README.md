

# Bank Customer Churn Analysis Dashboard

An end-to-end **Power BI** data analytics project focused on analyzing customer churn using demographic, financial, and behavioral data. The solution transforms raw customer data into actionable business insights through interactive dashboards, DAX measures, and an optimized data model.

## Overview

Customer churn is one of the most important business metrics in the banking industry. This project helps identify customers who are more likely to leave by analyzing customer demographics, account balance, activity status, and financial behavior.

The entire data cleaning, transformation, modeling, and visualization workflow was completed within **Power BI**.

## Tech Stack

- **Power BI Desktop**
- **Power Query** – Data Cleaning & Transformation
- **DAX** – Measures & Business KPIs
- **Data Modeling** – Relationships and Star Schema (Power BI)

## Key KPIs

- Customer Count
- Active Customers
- Churn Rate
- Total Account Balance

## Features

- Built an interactive customer churn dashboard with dynamic slicers.
- Performed data cleaning and reshaping using Power Query.
- Created a robust data model within Power BI for efficient analysis.
- Developed DAX measures for churn rate, customer count, active customers, and account balance.
- Designed drill-down visualizations to explore customer demographics and financial trends.
- Identified high-risk customer segments to support customer retention strategies.

## Business Questions Answered

- What is the overall customer churn rate?
- Which customer segments have the highest churn?
- How does account balance relate to churn behavior?
- Are active customers less likely to churn?
- Which demographic groups require stronger retention efforts?
